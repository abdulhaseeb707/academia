# Abdul Haseeb Khan — Academic & Professional Portfolio

A high-end, responsive personal portfolio designed for **Business Economics, Econometric Research, Financial Security & Islamic Finance**.

---

## 📁 Files Overview
- **`index.html`** — The complete master one-page website (Hero, Executive About, MPhil Research Agenda, Applied Projects, Career Experience, International Honors, Toolkit, Education, CV Hub, and Contact).
- **`project-inflation.html`** — Detailed econometric case study page for the *Inflation and Corporate Profitability* research project.
- **`styles.css`** — The complete styling system with Dark/Light theme mode, glassmorphic cards, gold accents, and responsive layout.
- **`script.js`** — Interactivity scripts (Theme toggle, mobile navigation drawer, infinite ticker loop, email copy with toast alert, scroll-spy, and fallback avatar).
- **`profile.jpg`** *(Optional)* — Drop your profile photo into this folder with the name `profile.jpg` or `profile.png`, and the website will automatically display it.
- **`cv.pdf`** *(Optional)* — Place your CV/Resume PDF in this folder named `cv.pdf` so visitors can download it with 1 click.

---

## 🚀 How to View Locally
Simply double-click `index.html` to open it in any web browser, or run:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

## 🌐 100% Free Deployment (No Domain Purchase Needed)

You can host this website completely for free with HTTPS security and high speed.

### Method 1: GitHub Pages (Recommended)
1. Go to [github.com](https://github.com) and log in to your account (`abdulhaseeb707`).
2. Create a new repository named exactly:
   ```
   abdulhaseeb707.github.io
   ```
   *(Make sure the repository is set to **Public**).*
3. Upload all the files inside this `files` folder directly to the repository:
   - `index.html`
   - `project-inflation.html`
   - `styles.css`
   - `script.js`
   - `profile.jpg` *(your photo)*
   - `cv.pdf` *(your resume)*
4. Once committed, your website will be live in ~1 minute at:
   ```
   https://abdulhaseeb707.github.io
   ```

### Method 2: Vercel (Drag-and-Drop)
1. Go to [vercel.com](https://vercel.com) and sign up with your GitHub account.
2. Click **Add New Project** → Import Git repository or drag-and-drop this folder.
3. Click **Deploy**. Your site will be live instantly with a free `.vercel.app` URL.
